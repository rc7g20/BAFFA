# 獸骨資料分析工具

動物考古獸骨清單的基礎分析工具。讀取遺址的原始清單（csv 或 xlsx），用勾選、篩選、拖曳等方式即時重算各項結果，並畫出可調整樣式的圖表。

- **單一檔案、免安裝**：整個工具就是一個 `index.html`，不需要網路、不需要安裝任何程式或函式庫。
- **資料不離開你的電腦**：所有計算都在瀏覽器中進行，清單不會上傳到任何地方。
- **可安裝為應用程式**：從網站開啟後可「安裝」到電腦或平板，之後離線也能使用。

## 功能

| 分頁 | 內容 |
|---|---|
| 物種相 | NISP、百分比（含／不含 UN 與體型分級）、重量與重量百分比；可依綱／目／科／屬／物種計算，或只看某一群（例如 綱＝鳥綱、科＝鹿科）；名稱合併、排序、排除 |
| MNI | 側別 MNI（同側同部位件數最大值）與區位 MNI（區位 1–8 重疊即為不同骨，以圖著色求最少骨數）；每個物種可勾選採計部位 |
| 骨骼部位 | 依顱部、軀幹、近端多肉骨骼、遠端少肉骨骼分組；不分側別、左右對照、區域小計；可排除特定部位（例如牙齒） |
| 性別 | 掃描備註與性別欄的判定詞，預設只採計犬齒判定；每筆可手動修改 |
| 年齡 | 齒位磨耗整合；磨耗寫法 → Lemoine 分數（可修改）；Lemoine et al. (2014) Specific／Simplified-A／Simplified-B 年齡組；存活曲線與死亡率，可依文化層等欄位分組比較 |
| 表面痕 | 切割、燒炙、啃咬依骨骼部位的樞紐表；不同寫法可歸類 |
| 臼齒測量 | 豬 M1／M2／M3 的 GL、WA、WP、WM；疑似離群標示；散點圖與直方圖 |

圖表可調整圖型、顏色、**非顏色的填滿圖樣**（斜線、點點、交叉、方格…，適合黑白印刷）、點形狀、虛線、透明度、堆疊、座標範圍等，並匯出 PNG（可指定公分＋DPI，會寫入 DPI 資訊）或 SVG。表格可直接複製貼到試算表，或匯出 CSV。

## 使用方式

### 方式一：直接開啟網站
到本儲存庫的 GitHub Pages 網址開啟即可使用。用 Chrome 或 Edge 開啟時，網址列會出現「安裝」圖示，安裝後可像一般應用程式一樣從桌面或主畫面開啟，離線也能使用。

### 方式二：下載後離線使用
下載 [`index.html`](index.html)（按檔案頁面右上角的「Download raw file」），放在電腦任何位置，用 Chrome 或 Edge 開啟即可。

### 載入資料
1. **電腦（Chrome／Edge）**：按「選擇資料夾」，選擇放遺址資料的上層資料夾，並允許編輯。工具會列出含 csv／xlsx 清單的子資料夾（每個遺址一個子資料夾）。設定、圖表、表格會直接存回該遺址的「分析結果」資料夾。
2. **平板、Safari、Firefox**：這些瀏覽器不能直接讀寫資料夾，請按「選擇檔案（平板）」選清單（可同時選測量值解析工具輸出的「物種_長表_*.csv」）。設定會存在這台裝置的瀏覽器中，也可下載備份；圖表與表格以下載方式儲存。

建議的資料夾結構：

```
獸骨資料整理/                 ← 選這個資料夾
├─ 程式/設定/                  ← （選用）所有遺址共用的對照表
│   ├─ 骨骼分類.csv
│   ├─ 物種別名.csv
│   └─ 側別對照.csv
├─ 遺址A/
│   ├─ 遺址A_ALL.csv           ← 原始清單（csv 或 xlsx）
│   ├─ 遺址A_ALL_測量長表_日期/  ← （選用）測量值解析工具的輸出
│   └─ 分析結果/                ← 工具自動建立
└─ 遺址B/ …
```

### 清單欄位
載入時會自動辨認欄名，找不到必要欄位時會請你指定（存成 `分析結果/欄位對照.csv`）。

| 標準欄位 | 可辨認的欄名（不分大小寫） | |
|---|---|---|
| 物種 | 物種、種、Species、Taxon | 必要 |
| 骨骼 | 骨骼、骨骼部位、部位、Element、Bone | 必要 |
| 數量 | 數量、Qty、NISP、件數、Count | 沒有時每筆算 1 |
| 側 | 側、側別、Side | |
| 區位 | 1、2、3 … 8（有紀錄填 v 即可） | 區位 MNI 用 |
| 其他 | 流水號、備註、切割、燒炙、啃咬、重量、性別（sex）、文化層、綱、目、科、屬 | |

骨骼與側別的寫法若不在對照表中，載入時會列出來讓你歸入既有部位或新增，結果寫入 `程式/設定/`（或瀏覽器中），以後所有遺址共用。

## 開發

原始碼在 `src/`：

| 檔案 | 內容 |
|---|---|
| `core.js` | 讀檔、名稱正規化、各項分析的計算規則 |
| `charts.js` | SVG 圖表與 PNG／SVG 匯出 |
| `ui.js` | 介面 |
| `xlsx.js` | xlsx 讀取（使用瀏覽器內建的解壓縮，無外部函式庫） |
| `template.html` | 頁面與樣式 |

修改後執行 `python src/build.py`，會重新產生根目錄的 `index.html`。`config/` 是預設對照表的範本，可複製到你的 `程式/設定/` 後自行擴充。
